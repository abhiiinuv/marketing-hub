GUI agents run inside Traycer chat tabs. They are the default surface for structured AI work.

## Capabilities

GUI agent chats can show:

- streaming assistant output
- reasoning and tool activity
- file changes
- approval requests
- todo lists
- accumulated diffs
- queued messages
- agent-to-agent messages
- context usage

## When to Use GUI Agents

Use GUI agents when:

- you want to inspect tool output and changes in one place
- the work should stay tied to an Epic
- you want to hand off to another agent
- you want another agent to message or inspect the conversation
- you need review and verification loops

## Supported Providers

GUI chats support Claude Code, Codex, OpenCode, Traycer, and Cursor, depending on your provider setup.
