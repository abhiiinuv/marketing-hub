Agents are the execution layer in Traycer. They can run as GUI chats, terminal-backed sessions, or delegated child agents inside an Epic.

## What Traycer Adds

Traycer gives agents:

- shared project context
- persistent workspace state
- provider and model selection
- permission controls
- structured handoffs
- agent-to-agent messaging
- review and verification loops

The goal is not to replace your preferred coding agent. The goal is to make multiple agents work inside one coherent development workspace.

## Agent Modes

Agents can run in:

- **Regular Mode**: direct coding-agent work with Traycer context.
- **Epic Mode**: structured work against specs, tickets, and shared Epic context.

See [Regular vs Epic Mode](/agents/regular-vs-epic-mode).
