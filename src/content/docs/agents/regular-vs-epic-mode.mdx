Traycer agents can run in two modes.

## Regular Mode

Regular Mode is a native coding-agent experience with Traycer context and controls.

Use it for:

- small fixes
- focused refactors
- quick code review
- repository exploration
- direct implementation

Regular Mode keeps the workflow lightweight: pick an agent, describe the task, inspect results, and continue.

## Epic Mode

Epic Mode is the structured Traycer planning experience.

Use it for:

- multi-step features
- ambiguous requirements
- specs and tickets
- multiple agents
- review and verification loops
- preserving long-running project intent

Epic Mode gives every tab in the Epic access to shared context.

## Rule of Thumb

Start in Regular Mode when the work fits in one conversation. Start in Epic Mode when the work needs structure, shared context, or multiple agents.
