Traycer is fully open source and free to use. The goal is to make AI development infrastructure inspectable, extensible, and owned by the people building with it.

Open infrastructure matters because coding agents are becoming part of the development stack. The tools that coordinate them should be auditable, portable, and shaped by developers rather than locked behind a single model provider.

## What This Means

- You can use Traycer without paying for a Traycer model plan.
- You can connect agent accounts you already use.
- You can inspect and contribute to the codebase.
- You can build workflows around open protocols instead of one-off prompt copying.

## Bring Your Own Agents

Traycer coordinates agents such as Claude Code, Codex, OpenCode, and Cursor. Each provider keeps its own authentication model; Traycer gives them a common workspace, context model, and handoff layer.

## Project Direction

Traycer focuses on open agent coordination:

- persistent project workspaces
- GUI and terminal agent surfaces
- AI-to-AI handoffs
- agent-to-agent communication
- structured Epic workflows
- review and verification loops
