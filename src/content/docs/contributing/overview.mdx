Traycer is open source. Contributions can improve the app, agent protocol, provider integrations, docs, tests, and developer tooling.

## Before Contributing

- Read the repository README.
- Install Bun and Node versions required by the repo.
- Run the relevant workspace checks before opening a pull request.
- Keep docs updated when product behavior changes.

## Useful Commands

```bash
bun install
bun run compile
bun run lint
bun run test
```

For full local setup, see [Local development](/contributing/local-development).

## Contribution Areas

- agent protocol and coordination
- GUI app workflows
- terminal-agent support
- provider integrations
- Epic workspace features
- review and verification flows
- docs and onboarding
