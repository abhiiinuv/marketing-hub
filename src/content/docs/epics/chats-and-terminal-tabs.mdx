Epics support both GUI chat tabs and terminal agent tabs.

## Chat Tabs

Chat tabs are best for structured interaction:

- planning
- discussion
- tool output
- file changes
- approval queues
- review notes
- agent-to-agent messages

Use chat tabs when the work benefits from visible state and rich conversation history.

## Terminal Tabs

Terminal tabs are best for native CLI workflows:

- Claude Code terminal sessions
- Codex terminal sessions
- OpenCode terminal sessions
- provider-specific commands
- interactive implementation work

Use terminal tabs when the provider's native terminal behavior is part of the workflow.

## Together

A common pattern is to plan in a GUI chat, implement in a terminal tab, then review the resulting diff in another GUI chat.
