An Epic is a persistent workspace for project-sized AI development. It keeps the work organized across specs, tickets, chats, terminal agents, diffs, and reviews.

Use an Epic when the work needs more than one conversation.

## What an Epic Contains

- specs for intent and design decisions
- tickets for implementation slices
- GUI chat tabs
- terminal agent tabs
- file and diff views
- review artifacts
- execution history
- shared context for every agent in the workspace

## Why Epics Exist

AI agents drift when important context stays hidden in scattered chats. Epics preserve the "why", the constraints, and the current project state so agents can continue from the same source of truth.
