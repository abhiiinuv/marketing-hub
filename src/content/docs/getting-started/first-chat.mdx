Regular Mode is the fastest way to start: pick a workspace, choose an agent, and ask it to work on the code.

## Create a Chat

<Steps>
  <Step title="Choose the repository">
    Select the workspace where the agent should read and edit code.
  </Step>
  <Step title="Choose the agent">
    Pick a provider, model, reasoning level, speed tier if available, and permission mode.
  </Step>
  <Step title="Describe the task">
    Ask for a concrete change, investigation, bug fix, refactor, or review.
  </Step>
  <Step title="Review changes">
    Use the chat's accumulated changes, diffs, and tool output to inspect what happened.
  </Step>
  <Step title="Continue or hand off">
    Keep iterating, move to another agent, or create an Epic when the work needs more structure.
  </Step>
</Steps>

## Good First Prompts

- "Find the auth flow and explain where session refresh happens."
- "Refactor this component to separate data loading from presentation."
- "Review the current diff for regressions before I commit."
- "Implement the smallest safe fix for this failing test."

## Next
