Install Traycer from the project's release channel, then launch the app and open a repository.

## Requirements

- A supported desktop operating system.
- Git installed and available from your shell.
- At least one coding-agent provider if you want to run agent sessions.

Provider-specific requirements:

- Claude Code requires the Claude Code CLI.
- Codex requires the Codex CLI.
- OpenCode requires the OpenCode CLI.
- Cursor GUI chats require a Cursor API key.

## After Install

Open Traycer and confirm:

1. Your repository appears in the workspace picker.
2. Settings are accessible from the app header.
3. The Providers panel can detect or accept paths for your installed agents.

Then continue to [Connect providers](/getting-started/connect-providers).
