Traycer can use Claude Code as both a GUI agent and a terminal-backed agent.

## Setup

1. Install and authenticate Claude Code outside Traycer.
2. Open **Settings -> Providers**.
3. Select **Claude Code**.
4. Enable the provider.
5. Choose a detected CLI binary or add a custom path.
6. Refresh provider availability.

## GUI Use

Use Claude Code in a GUI chat when you want Traycer to show structured messages, tool activity, file changes, and handoff context.

## Terminal Use

Use Claude Code as a terminal agent when you want the provider's native terminal workflow inside an Epic.

## Tips

- Keep provider authentication working in your shell before debugging Traycer.
- Use permission modes deliberately.
- Use Epic Mode when Claude Code should work from specs and tickets.
