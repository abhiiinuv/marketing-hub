Traycer can use Codex as both a GUI agent and a terminal-backed agent.

## Setup

1. Install and authenticate the Codex CLI.
2. Open **Settings -> Providers**.
3. Select **Codex**.
4. Enable the provider.
5. Choose a detected CLI binary or add a custom path.
6. Refresh provider availability.

## GUI Use

Use Codex in GUI chats for structured implementation, review, reasoning, and handoffs.

## Terminal Use

Use Codex as a terminal agent when you want the native CLI session visible inside the Epic workspace.

## Tips

- Use model and reasoning controls to match task complexity.
- Use handoffs when Codex should continue work started by another provider.
- Use review workflows for a second pass over another agent's changes.
