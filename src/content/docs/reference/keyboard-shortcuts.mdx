Traycer exposes keybindings in **Settings -> Keybindings**. Use the settings page as the source of truth for your installed version.

## Common Shortcut Categories

- open command palette
- switch tabs
- create a new chat or Epic
- focus composer
- open settings
- navigate within an Epic
- open or close panels
- find in page

## Customization

If a shortcut conflicts with your editor or operating system, change it in Keybindings settings.

## Recommendation

Start with command palette search. It is usually faster than memorizing every shortcut at once.
