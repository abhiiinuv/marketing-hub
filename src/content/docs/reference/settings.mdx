Traycer settings are organized by the part of the workflow they control.

## General

General app preferences, workspace defaults, and local behavior.

## Appearance

Theme, typography, artifact icon colors, and UI preferences.

## Providers

Provider availability, CLI binary selection, API keys, custom paths, account metadata, and terminal-agent arguments.

See [Provider setup](/agents/provider-setup).

## Keybindings

Keyboard shortcuts for navigation and common commands.

## Shell

Shell path, shell arguments, and environment overrides used by terminal workflows.

## Worktrees

Management for project worktrees created or used by Traycer workflows.

## Agents

Agent-related defaults such as provider behavior, permissions, and mode selection where available.
