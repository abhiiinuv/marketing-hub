Epic Mode is the structured Traycer workflow. It turns an open-ended project into a workspace where agents can plan, implement, review, and continue from shared context.

## Best For

- ambiguous requirements
- project-sized implementation
- multiple agents or models
- specs and tickets
- review and verification loops
- long-lived project intent

## Epic Mode Flow

<Steps>
  <Step title="Capture intent">
    Start with the user goal, constraints, and relevant code areas.
  </Step>
  <Step title="Create specs">
    Preserve product and technical intent in focused documents.
  </Step>
  <Step title="Break into tickets">
    Turn specs into implementation slices with acceptance criteria.
  </Step>
  <Step title="Run agents">
    Use GUI chats and terminal agents to implement, review, and verify.
  </Step>
  <Step title="Record findings">
    Keep review comments, diffs, and decisions inside the Epic.
  </Step>
</Steps>

## Why It Works

Epic Mode gives agents a shared memory of the project. That makes handoffs and agent-to-agent communication practical because the receiving agent can inspect the same workspace context.
