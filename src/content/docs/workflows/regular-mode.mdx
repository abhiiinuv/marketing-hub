Regular Mode is the direct way to use Traycer. Pick a provider, model, workspace, and permission level, then ask the agent to work.

## Best For

- focused bug fixes
- quick code exploration
- small refactors
- one-off reviews
- direct implementation
- asking a model to explain part of a codebase

## What Traycer Adds

Regular Mode keeps the provider experience familiar while adding:

- workspace selection
- model and reasoning controls
- permission controls
- file-change visibility
- handoffs to other agents
- a path into Epic Mode if scope grows

## When to Switch to Epic Mode

Switch when:

- the task has multiple phases
- requirements need to be captured
- multiple agents should coordinate
- review findings need durable tracking
- you want specs and tickets to guide the work
